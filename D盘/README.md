# D 盘知识库部署说明

目标本机路径：**`D:\第二大脑`**

云端无法直接写入你的 Windows D 盘。本目录是可完整同步到 D 盘的 Vault 包：

| 环境 | 路径 |
|------|------|
| 本仓库（可 clone / 下载） | `D盘/第二大脑/` |
| 云端 WSL 风格镜像 | `/mnt/d/第二大脑/` |
| 你的 Windows 本机（请创建） | `D:\第二大脑\` |

## 本机三步（必做）

1. 在资源管理器中新建文件夹：`D:\第二大脑`
2. 将本仓库中 `D盘/第二大脑/` **全部内容**复制到 `D:\第二大脑\`  
   （使 `D:\第二大脑\AGENTS.md` 与 `D:\第二大脑\.obsidian\` 直接位于仓库根）
3. 打开 Obsidian → **Open folder as vault** → 选择 `D:\第二大脑`

不要把 AF 研究仓库根目录（含 `immune`）当成 Vault；Vault 根必须是 `第二大脑` 这一层。

## Agent 约定

知识库维护以 **`D:\第二大脑`**（云端对应 `D盘/第二大脑` 或 `/mnt/d/第二大脑`）为唯一 Vault 根；开工前先读其中的 `AGENTS.md`。
