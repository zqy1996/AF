## 1. 三层架构

```
Raw   → 原始素材（只读，不擅自改删）
Wiki  → 可复用知识弹药（Agent 提炼与更新的主战场）
Schema→ 本文件 AGENTS.md（工作规则）
```

| 层 | 路径 | 原则 |
|----|------|------|
| Raw | `raw/` | 永远保留原文；禁止擅自修改、删除或覆盖 |
| Wiki | `wiki/` | 不是资料摘要，而是可复用知识；用 `[[双链]]` 连接 |
| Schema | `AGENTS.md` | 统一规则；变更前先询问主人 |

辅助文件：

- `index.md` — Vault 总览与导航入口
- `log.md` — 变更日志（**只追加**）
- `backup/` — 修改已有 Wiki 笔记前的备份区

## 2. 核心工作规则（强制）

### 2.1 先搜索，再创建

新资料进入后，**先搜索 Wiki**（标题、关键词、双链、相关目录），优先更新已有知识页面，避免重复页面。

### 2.2 Raw 不可变

- Raw 永远保留原始内容。
- 禁止擅自修改、删除或覆盖 Raw 中的任何文件。
- 需要「清洗版」时，在 Wiki 新建/更新页面，不要改 Raw。

### 2.3 Wiki 是知识弹药，不是摘要册

不要采用「一个 Raw → 一个摘要」的模式。

正确流程：

```
新素材 → 搜索已有知识 → 提取新增信息 → 更新相关 Wiki → 建立双链 → 记录 log.md
```

一份 Raw 可以同时更新多个 Wiki 页面，例如：

- `wiki/titles/` — 标题模式
- `wiki/topics/` — 选题方向
- `wiki/structures/` — 写作/文章结构
- `wiki/tools/` — AI / 生信 / 创作工具
- `wiki/audience/` — 读者需求与痛点
- `wiki/writing/` — 写作经验与风格规律
- `wiki/accounts/` — 对标账号
- `wiki/articles/` — 爆款/对标文章拆解

### 2.4 来源与可信度

- 重要事实与爆款拆解必须保留：**原始来源、链接、发布日期**。
- 无法确认的信息标记为 **`待核实`**。
- 引用评论与用户反馈时 **匿名处理**（去掉昵称、头像、可识别 ID）。

### 2.5 去重检查

新建对标账号、工具、概念、结构模板等页面前，必须检查 Wiki 是否已存在同义/近义页面；若存在则合并更新，并在 `log.md` 记录。

### 2.6 修改前备份

修改**已有** Wiki 笔记前，先将当前版本复制到 `backup/`，建议命名：

```
backup/YYYY-MM-DD_HHMM_<原相对路径用__代替斜杠>.md
```

示例：`backup/2026-10-08_1530_wiki__titles__钩子句式.md`

### 2.7 双链优先

使用 Obsidian `[[双链]]` 连接相关知识，避免孤立笔记。新建页面时至少建立一条有意义的回链或相关链。

### 2.8 log.md 只追加

`log.md` **只追加、不改写历史**。记录重要的：新建、更新、合并、待确认事项。

### 2.9 不擅自删除；结构变更先问

- 不擅自删除文件。
- 涉及知识库目录结构或本 `AGENTS.md` 核心规则变化时，**先询问主人**。
- 只有某类内容明显增多时，才建议新增目录或规则；**不要一开始过度设计**。

## 3. 自生长原则

1. **沉淀优先于堆叠**：重复出现的标题模式、文章结构、选题方向、读者痛点、工具信息、写作规律 → 逐渐沉淀为独立 Wiki 页面。
2. **增量更新**：每次只写入「新增信息」，并标明来自哪份 Raw（路径或 `[[链接]]`）。
3. **跨板块复用**：临床 / 生物信息技术 / 文献 的方法论可互相引用；用双链与标签区分语境，而不是复制三套平行目录。
4. **为未来 Agent 留接口**：写作、测评、对标、书稿、自动初稿等 Skill 应读取 Wiki 对应子目录，而不是硬编码提示词里的临时知识。

## 5. 推荐入库流程（新素材）

1. 将文件放入 `raw/inbox/`（或已明确类型则直接放入对应 Raw 子目录）。
2. 读取本文件（`AGENTS.md`）。
3. 在 Wiki 中搜索：账号 / 标题 / 选题 / 结构 / 工具 / 读者 / 写作经验。
4. 提取新增信息；更新已有页面，或在确认不存在后新建。
5. 写明来源（Raw 路径、链接、日期）；不确定处标 `待核实`。
6. 建立 `[[双链]]`。
7. 在 `log.md` 末尾追加一条变更记录。

## 6. 三大板块标签约定（轻量，不过度设计）

在 Wiki 笔记 frontmatter 或文首使用：

- `#临床`
- `#生物信息技术`
- `#文献`

一篇笔记可打多个标签。目录不按板块强拆，避免早期过度设计。

## 7. Agent 禁止事项

- 不覆盖、不改写 Raw
- 不删除任何文件（除非主人明确指令）
- 不在未搜索的情况下批量新建「摘要页」
- 不把无法核实的论断写成确定事实
- 不在评论引用中暴露真实用户身份
- 不擅自修改本 `AGENTS.md` 或增删顶层目录
