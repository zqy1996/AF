# cobusgreyling/llm-wiki（参考实现）

## 一句话摘要

Karpathy LLM Wiki 的开源工具包与模板：CLI + MCP + 示例 vault（demo/research/reading/business）。

## 关键信息 / 弹药

- 标准页型：entities / concepts / sources / answers / synthesis / contradictions  
- 操作与 Schema 对齐：ingest / query / lint  
- `wiki ingest-status`、`wiki lint`、`wiki search` 可在规模变大后引入  
- 示例证明：一份 raw 可联动 15+ wiki 页  

## 与本库关系

本库**采纳其 Schema 与页型**，暂不强制安装 CLI；创作弹药目录（titles/topics…）保留以服务内容生产。
